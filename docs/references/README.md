来源：<https://cardconjurer.com/creator>　截图：`cardconjurer-creator.png`

| 页面底色 | `#161618`（rgb 22,22,24） |
| 主要面板 | `#363636`（rgb 54,54,54） |
| 叠加层 | `rgba(255,255,255,0.04)` / `0.12`（玻璃感） |

| 字体 | Montserrat |
| 字号阶梯 | 16px / 14.4px / 10.8px（10.8 用于标签） |

| 预览卡片尺寸 | 320×320 |
| 按钮 | 透明底、圆角 4px、左右内边距 16px、字号 14.4px |

可抄：**左侧一条竖向控制面板 + 右侧大面积预览舞台**；面板里的分区用选项卡切换
（Frames / Text / Images），而不是把所有字段堆成一长列；控件紧凑、圆角小。

## HearthCards — 卡牌编辑器（卡片网格 + 编辑面板同屏）

来源：<https://www.hearthcards.net/>　截图：`hearthcards.png`

| 项目 | 实测值 |
| --- | --- |
| 页面底色 | rgb(19,16,11)（近黑棕） |
| 主要面板 | `#ffffff` / `#f0f0f0` |
| 字号 | 正文 16px（占比最高），另有 17px / 12px |
| 按钮 | 圆角 6px，主色蓝 `#0d6efd` |

导出入口（Export JSON / Download Preview Image）就放在编辑区底部，不做二级菜单。

## IFTTT — “如果……就……”的句子式表达

来源：<https://ifttt.com/explore>　截图：`ifttt-explore.png`

可抄：一条自动化用**一句可读的话**描述（If 触发 → Then 动作），每一段是一个可点的槽位。
这正是"效果行"要的语法；不要用节点连线表达分支。

## 结论（落到我们自己的设计上）

1. 两个卡牌设计器都是**深色工作台**——因为卡面本身色彩浓，深底能让成品跳出来。
   我们现在是浅色编辑器，建议：**工具区保持中性浅色、卡面预览区用深色舞台**，
   两边都占便宜。
2. 面板宽度参考 320–412px；我们的三栏定 300 / 自适应 / 360 是合理区间。
3. 字号阶梯照抄 16 / 14.4 / 12 三档，控件圆角 4–6px，行高紧凑（32–36px）。
4. 每张卡的效果不要用选项卡分流，用**一条条句子行**；选项卡留给"属性 / 描述 / 资源"这类平级切换。

## 卡面预览的同步方式（2026-09-10 补）

预览不是照着游戏画的，是用脚本抽出来的：

```bash
cd Python联机版
python tools/extract_card_css.py          # 默认输出到 模组编辑器/prototype/game-card.css
```

抽出来的内容包括 `.card` 相关规则、`:root` 变量、`@font-face`、
`html.fonts-loaded-main`（字体加载后切到 Kreadon）和 `[data-theme="dark"]` 的主题变量；
字体 URL 会被改写成编辑器内的 `./fonts/...`，字体文件放在 `prototype/fonts/`。
游戏改版后重跑一次即可，**不要手改 `game-card.css`**。
